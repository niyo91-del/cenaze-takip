# Cenaze Takip (Android)
Cenaze yıkama sırasını otomatik dağıtan, çevrimdışı çalışan uygulama.

## APK alma (bilgisayarda kurulum gerekmez)
1. github.com'da yeni bir depo açın, bu klasörün içindekileri yükleyin.
2. Depoda **Actions** sekmesi → "APK olustur" çalışır (≈3 dk).
3. Bitince çalışmanın altındaki **CenazeTakip-APK** dosyasını indirin, zip'ten çıkan `app-debug.apk`'yı telefona atıp kurun
   (Ayarlar → "Bilinmeyen kaynaklardan yüklemeye izin ver").

Alternatif: Android Studio ile klasörü açıp Build → Build APK.
Uygulama arayüzü: `app/src/main/assets/index.html`
